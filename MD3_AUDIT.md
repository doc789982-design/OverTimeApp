# Аудит дизайн-системы OVERTIMETAB против Material Design 3

Дата: 26.09.2026 · Проверено: `components/AppTheme.qml` (242 строки, все токены),
`AppButton`, `AppShadow`, контрасты посчитаны по WCAG 2.1.

## Вердикт

Система построена **по мотивам MD3 с осознанными деловыми упрощениями**.
По числовым токенам совпадение высокое (~75%): сетка, скругления, высоты теней,
длительности анимаций и 38% для disabled взяты почти дословно из спецификации.
Главные расхождения — не в цифрах, а в **доступности**: 4 контрастные пары
не проходят WCAG AA, и самая заметная — белый текст на брендовом синем
в тёмной теме (2.93:1 при норме 4.5:1).

| Раздел MD3 | Соответствие | Комментарий |
|---|---|---|
| Shape (формы) | ★★★★☆ | значения 4/8/12/16 — точно токены MD3; нет 28 (extra-large) |
| Layout / сетка | ★★★★★ | отступы кратны 4dp, ряд 2–64 |
| Elevation (тени) | ★★★★☆ | 5 уровней с y/blur ≈ MD3; вместо surface tint — плоские константы |
| Color (структура ролей) | ★★★★☆ | primary/surface-иерархия/on-accent/error/контейнеры — как в MD3 |
| Color (доступность) | ★★☆☆☆ | 4 пары ниже AA — см. таблицу контрастов |
| Typography | ★★★★☆ | Roboto ✓, 16/14/12 и 32/28/24 = шкала MD3; нет 22, есть лишние 20/40 |
| Motion | ★★★★☆ | длительности в диапазонах MD3; кривые Expo вместо emphasized |
| States | ★★★★☆ | press/disabled по MD3; hover в светлой теме 4% вместо 8% |
| Components | ★★★☆☆ | кнопки: 36px и радиус 8 вместо 40px и full; scale при нажатии |
| Dark theme | ★★★★☆ | bgBase #1C1C1E ≈ MD3 surface; bgPanel #121212 — наследие MD2 |

## 2. Сетка и отступы — эталон

2/4/8/12/16/24/32/48/64 — всё кратно 4dp, как требует MD3.
Брейкпоинты 600/1024/1440 против MD3 600/840/1200 — свои, но компактный
порог совпадает. maxContentWidth 1200 — разумное ограничение канваса.

## 3. Elevation и тени

Уровни 1–5 (y/blur: 1/3, 3/6, 4/8, 8/12, 12/16) практически повторяют MD3.
Прозрачность 12% днём — по спецификации; 40% ночью — компенсация отсутствия
тонирования. Реализация PNG-растяжкой вместо DropShadow — легитимная
оптимизация, на вид не отличимо.

**Отклонение:** в MD3 тёмной теме высота выражается **surface tint** —
поверхность подкрашивается primary (tone растёт с уровнем). У нас плоские
константы (#242426 → #2C2C2C → #333333) — серая лестница вместо
тонированной. Это выбор в пользу нейтральности, не ошибка.

## 4. Цвет: структура ролей — да, доступность — нет

Роли повторяют MD3: primary (accentBrand), поверхность (base → surface →
cell → elevated → modal — аналог surface…surfaceContainerHighest),
on-primary (textOnAccent), error (accentDanger), контейнеры (bgXSoft ≈
xContainer), on-surface-variant (textSecondary). Структурно — отлично.

## 6. Motion

Длительности 100/150/200/250/400 мс — все внутри MD3 диапазонов
(short 50–200, medium 250–400). Кривые OutExpo/InExpo/InOutExpo —
экспоненциальное семейство; MD3 standard/emphasized —
cubic-bezier(0.2, 0, 0, 1). Характер близкий (быстрый старт, длинный
хвост), но формально не токены. В QML есть `Easing.Bezier` +
`easing.bezierCurve: [0.2, 0, 0, 1]` — можно получить каноническую
кривую без потерь.

## 7. Состояния

| Состояние | Программа | MD3 | Вердикт |
|---|---|---|---|
| Disabled | 38% | 38% | ✓ точное попадание |
| Press (тёмная/светлая) | 12% / 8% | 10–12% | ~ светлая мягче |
| **Hover (тёмная/светлая)** | 6% / 4% | 8% | ✗ светлая вдвое мягче |
| Selected | 15% / 10% | — (свой токен) | ~ |

Вместо state layer у части контролов scale 0.98 при нажатии — в MD3
масштабирования кнопок нет (только ripple/state layer). Мелочь, но своя.

## 8. Компоненты

**Кнопка** — главное отклонение: высота 36 (MD3 40), радиус 8
(MD3 full = stadium, полностью скруглённая), минимальная ширина 100
(MD3 64 — не проблема). Выглядит «деловито», но это не MD3-кнопка.
Focus-кольцо 2px с 50% brand — свежие MD3-спеки тоже требуют внешнее
кольцо 3px: близко.

**Прочее:** чекбоксы с анимацией пути, поля, карточки, снекбары-тосты —
по духу MD3, с фирменными деталями (искры праздников, морфинг панелей).

## Что сознательно НЕ по MD3 (и это нормально)

- Condensed-шрифт для заголовков таблиц;
- PNG-тени вместо гауссова размытия (производительность);
- z-архитектура 0…99999 (в MD3 нет токенов слоёв);
- stateSelected как цвет (в MD3 — state layer поверх primary);
- фокус-кольцо 2px/50% вместо 3px.

## Десктоп-контекст: почему темп и размеры у нас не мобильные

MD3 спроектирован touch-first (пальцы неточные → цели 48dp, поля 56dp,
тягучие 300–500 мс анимации, волны вместо hover). У нас мышь и плотный
табель, поэтому берём у MD3 только палитру/контрасты/state layers/форму
контролов, а размеры и тайминги — из десктопных систем:

- **Fluent 2** (Microsoft, Windows 11) — контролы 32px, мгновенный hover,
  press без волн, анимации 150–250 мс («productive»). Эталон: приложение
  WinUI Gallery в Microsoft Store.
- **IBM Carbon** — корпоративная плотность: таблицы, формы, режим compact
  (переключатель плотности прямо на carbondesignsystem.com).
- **GNOME HIG / KDE HIG** — дисциплина анимаций ≤200 мс (GNOME),
  размеры Qt-стека (KDE). Apple HIG (macOS) — сдержанность, 22–28px.

Принятые у нас числа: поля 44, кнопки 40, свитч 52×32 (компромисс
мышь/тач), hover 8% мгновенно, волны ≤380 мс, окна 150–250 мс.
